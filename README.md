# earthgoddess-website

Responsive portfolio website for a Khmer poet and spoken word artist promoting her upcoming musical.

## Built with

- **HTML5** — semantic structure
- **CSS3** — custom design tokens, mobile-first responsive
- **JavaScript** — vanilla (mobile menu toggle, dynamic footer year)
- **Google Fonts** — Fraunces (display) + Manrope (body)

## Features

- Single-page, scroll-based navigation with anchor links
- Mobile-responsive design (768px breakpoint, hamburger menu)
- SEO optimization: meta tags, Open Graph, JSON-LD structured data
- Custom color palette: warm earth tones (terracotta, gold, moss green)
- Smooth animations and hover effects
